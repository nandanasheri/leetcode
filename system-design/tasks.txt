2. Database Entities
entities : User, Task, Project
membership : User-Project, User-Task, Project-Tasks

Data Models - 
User :
name, user_id (PK), email
Project :
name, project_id (PK), owner_id
Task :
title, desc, task_id (PK), status, priority, due_date, create_date, project_id(FK)
User-Project:
user_id, project_id, role
User-Task:
task_id, user_id

Schema:
User (
    user_id UUID PRIMARY KEY,
    name VARCHAR
    email VARCHAR
)
Project (
    name VARCHAR
    project_id UUID PRIMARY KEY
    owner_id UUID Foreign key references User(user_id)
)
Task (
    title VARCHAR
    desc VARCHAR
    task_id UUID PRIMARY key
    status not null default 'todo'
    priority not null
)

UserProject (
    project_id references Project(project_id)
    user_id references User(user_id)
    role VARCHAR
    PRIMARY KEY (project_id, user_id)
)

APIs 
POST /project
GET /projects/{project_id}
GET /projects/{project_id}/tasks?status=todo&sort_by=due_date
